# AI Stack Trace Investigator

## Setup Instructions

To run this project, you will need to set up your environment variables:

1. Duplicate the `.env.example` file and rename it to `.env`.
2. Add your own OpenAI API key to the `.env` file.

```sh
cp .env.example .env
# Edit .env and add your OPENAI_API_KEY
```

3. Install the dependencies:
```sh
pip install -r requirements.txt
```

4. Run the application (refer to project documentation for specific start commands).
